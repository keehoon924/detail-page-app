# 상세페이지 카피 플레이북 (한국형)

## 대원칙
- **고객 언어로** 말한다. 스펙이 아니라 "그래서 내 삶이 어떻게 좋아지는가(베네핏)".
- **과장·허위 금지.** 근거(리서치)·스펙에 기반한다.
- 짧고 강하게. 한 문장 한 메시지. 모바일에서 읽힌다는 전제.

## 후킹 헤드라인 패턴 (s01)
- 문제 제기형: "아직도 ~ 때문에 고민하세요?"
- 결과 약속형: "~, 이제 ~하세요"
- 반전/의심형: "운전석 공기, 이제 의심하지 마세요"
- 숫자/구체형: "단 3초, ~"

## 프레임워크
- **AIDA**: Attention(후킹) → Interest(공감·문제) → Desire(베네핏·증거) → Action(CTA)
- **PASTOR**: Problem → Amplify(키움) → Story/Solution → Transformation → Offer → Response
- 13컷 전체가 위 흐름을 따르도록 배치한다.

## 톤&매너
- 입력 `brandGuide` 가 있으면 최우선. 없으면 카테고리에 맞춰 결정(예: 신뢰감 있는·미니멀 / 친근한·생활밀착).
- 톤은 `CopyDeck.tone` 에 한 줄로 명시.

## 13컷 섹션별 가이드
| 섹션 | 역할 | 카피 팁 |
|------|------|---------|
| s01-hero | 후킹 | 메인 헤드라인 1방 + 짧은 서브. 제품명·핵심가치 |
| s02-value | 핵심가치 한 줄 | 가장 강한 베네핏을 한 문장으로 |
| s03-empathy | 타겟 공감 | 페인포인트를 "내 얘기"처럼. 질문/공감 |
| s04-brand | 브랜드·제품 소개 | 신뢰·정체성. 왜 이 제품인가 |
| s05~07 | 핵심 특징 ①②③ | 특징→베네핏 전환. bullets 활용 |
| s08-usage | 사용법/시나리오 | 쉬움·일상 적용을 보여줌 |
| s09-detail | 디테일 컷 | 소재·마감·디테일로 품질 신뢰 |
| s10-spec | 스펙/사이즈 | 객관 정보. bullets/표 형태 |
| s11-trust | 신뢰/후기/인증 | 후기·인증·수치로 안심 |
| s12-shipping | 배송·교환 안내 | 명확·간결. 불안 제거 |
| s13-cta | 마무리 CTA | 행동 유도 + 혜택(한정/할인) 강조 |

## 출력 규칙
- 각 섹션: `headline`(필수), `subcopy`, `body`, `bullets[]`. 비울 항목은 빈 문자열/빈 배열.
- SEO 키워드는 헤드라인·바디에 **자연스럽게** 녹인다(키워드 나열 금지).
- 최종은 `CopyDeckSchema` 형식의 JSON (섹션 13개).
