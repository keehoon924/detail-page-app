# 상세페이지 디자인 시스템 v2

> "제한은 단순함을, 사고는 고급스러움을 낳는다." 템플릿에서 고르지 말고, 컷마다 역할에 맞게 설계한다.

## 0. 절대 원칙
- **반투명 박스(흰 글자 + 반투명 사각형)를 기본 패턴으로 쓰지 않는다.** 13컷 중 최대 1~2컷만 허용.
- **연속 3컷이 같은 레이아웃이면 안 된다.**
- 한 컷에서 시선이 가야 할 곳은 **1개**. 여백은 디자인이다.
- 배경은 **솔리드 컬러 섹션 + 실제 제품 사진 + 벡터 장식**이 기본. 사진 위 텍스트는 그라디언트 스크림/쉐도우로 가독성 확보.

## 1. 8대 레이아웃 요소 (조합해서 컷마다 다르게)

```
① 섹션 구분(divider)   웨이브(곡선) / 대각선 컷 / 없음 — 다음 섹션 색으로 채움
② 장식(decoration)     뱃지(pill·번호원·체크), 아이콘, 손글씨 악센트, 동그라미/화살표, 블롭
③ 다단(columns)        한 컷 안 2열·3열 (종류/구성품/기능 나열)
④ 리뷰(review)         별점 + 실제 리뷰 문구 + 사용자 아이디(마스킹: kim0***, @siy***)
⑤ FAQ                  Q&A 리스트(접이식 느낌) — Q는 강조색 원/배지
⑥ 비교표(comparison)   경쟁 vs 우리 / 일반 vs 프리미엄 — 우리 열 강조, 체크/엑스
⑦ 배경색 전환(flow)     컷마다 같은 색 패밀리 안에서 명도·채도로 부드럽게 전환
⑧ GIF 영역             사용자 GIF 업로드 위치 — 없으면 플레이스홀더 박스
```

## 2. 레이아웃 사고도구 (layout enum)
- `hero` — 후킹. 큰 헤드라인 + 손글씨 + 뱃지 + 제품 사진. 웨이브로 다음 컷 연결.
- `feature-split` / 비대칭 6:4·7:3 — 사진 한쪽, 카피 한쪽.
- `columns` — 2·3열 그리드(종류·기능·구성).
- `comparison` — 비교표.
- `review` — 별점·후기·평점.
- `faq` — Q&A.
- `steps` — 번호 플로우(사용법).
- `centered` — 이미지 없이 문장 힘으로(선언·전환).
- `gif` — GIF/움짤 영역.
- `full-bleed` — 감성 사진 풀블리드(텍스트 최소).

## 3. 컬러 — 카테고리+톤+감정에서 파생 (고정 팔레트 아님)
```
신뢰/안정 → 네이비·다크그레이·화이트   고급/프리미엄 → 블랙·골드·딥그린·버건디
활력/젊음 → 비비드·코랄·민트            자연/건강 → 그린·아이보리·베이지·어스톤
따뜻/안심 → 웜베이지·피치·소프트옐로     모던/세련 → 모노톤 + 포인트 1개
```
- 배경↔텍스트 대비 **4.5:1 이상** 필수(밝은 배경=어두운 글자, 어두운 배경=밝은 글자 — 자동 판정).
- 포인트 컬러(CTA·강조)는 전체의 **5~15%**만.
- 배경색은 컷마다 미세하게 달라지되 **같은 색 패밀리**(⑦ 전환 흐름).

## 4. 폰트 — 톤에서 파생
```
Pretendard   범용 고급(기본)        스포카한산스  테크·모던(전자기기)
Noto Sans KR 정보전달·안정          나눔손글씨/펜  손글씨 악센트(②)
GmarketSans  캐주얼·식품·젊은 타겟   나눔스퀘어    친근(유아·건강·반려)
```
- 톤→무게: 미니멀=가늘고 넓은 자간 / 자신감=굵고 좁은 자간 / 감성=중간굵기·넉넉한 행간.
- **숫자는 디자인 요소** — "99.95%", "130kcal" 등은 크게·강조색으로 별도 스타일.
- 모바일 본문 최소 16px, 헤드라인 최소 32px.

## 5. 이미지
- AI는 **배경만** 생성(텍스트/로고/워터마크 금지 프롬프트). 제품은 **실제 사진 누끼 후 합성**.
- 13컷 전체에서 제품 크기·색감·조명·배경 톤이 같은 가족으로 통일.

## 출력
- `DesignSpecSchema` JSON. 각 컷에 layout·divider·badge·decorations·columns/review/faq/comparison 등 필요한 요소만 채운다.
