# inputs/ — 제품 원본 정보

정보수집 에이전트가 읽는 입력을 여기에 둔다.

## 권장 구성
- `product.md` 또는 `product.txt` — 제품명, 핵심 특징, 스펙, 브랜드 톤, 타겟 고객 (자유 형식 텍스트)
- `images/` — 제품 사진·레퍼런스 이미지 (png/jpg). 정보수집·디자인 단계가 참고.

## 예시 (product.md)
```
제품명: 무선 차량용 공기청정기 AirPure X
타겟: 차량 출퇴근이 잦은 30~40대, 미세먼지/냄새 민감
핵심특징: 3단 헤파필터, USB-C 무선, 60dB 저소음, 한 손 크기
스펙: 크기 65x65x180mm / 무게 380g / 정화면적 5㎡ / 배터리 8시간
브랜드 톤: 깔끔하고 신뢰감 있는, 미니멀
```
